Build results land here, one folder per chapter (`output/chapter-01/…`).

- `chapter-NN.pdf` — final A4 PDF (only produced when every illustration exists and QA passes)
- `chapter-NN-DRAFT.pdf` — proof build with labelled illustration placeholders
- `qa-report.json` — the automated quality-control result for the last build
- `image-report.md` / `.json` — illustration progress (required, generated, approved, pending, rejected, missing, failed)
