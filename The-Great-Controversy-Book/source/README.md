# Source texts

## `gc1888-public-domain-scan/` — committed

Ellen G. White, *The Great Controversy Between Christ and Satan During the Christian Dispensation*,
eleventh edition, Pacific Press Publishing Company, Oakland, California, 1888. Copyright entered 1888.

- Scan: Library of Congress, via the Internet Archive, item `greatcontrover00whit`
  (https://archive.org/details/greatcontrover00whit). The Library of Congress states it "is unaware
  of any copyright restrictions for this item."
- Checked on download: the title page reads 1888, Pacific Press, and the text has 42 chapters and an appendix.
- The files are the scan's automatic text recognition, split by chapter. They contain recognition
  errors (broken words, stray characters, running heads) and are **not** fit to quote from without
  checking each quotation against the page images.

## `working-text/` — not committed

A clean digital edition of the same 1888 text, supplied by the project owner in eight PDF parts and
split by chapter. That edition carries an Ellen G. White Estate end-user licence (© 2010) limiting
it to personal use and forbidding derivative works; the project owner has stated that they hold
authorisation to use it for this book. It is used as the reading text for writing each study and is
kept out of the repository, so it is not redistributed. If this folder is missing, the eight PDFs
must be supplied again.

## How the sources are used

Each chapter study is an original explanation in plain English. Ellen White's ideas are paraphrased
and labelled; a few short sentences are quoted word for word and labelled "Ellen White's Words".
Every direct quotation is checked against both sources.
